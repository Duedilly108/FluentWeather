FluentWeather (Local)
=====================

A weather app for Windows with saved locations and weather icons in the taskbar.
Based on FluentWeather by Gabboxl, with additions by duedilly.

Saves locations and switches between them with one click.
Temperature and conditions icon in the system tray.
Hover over the tray icons for a range of selectable details.
Customize text size, background contrast, forecast length and language.


Requirements
------------
Windows 10 (version 1809 or later) or Windows 11, 64-bit.


Install
-------
1. Double-click FluentWeather-Setup.exe.
2. If Windows shows "Windows protected your PC", select More info, then Run anyway.
3. In the setup window, pick the options you want, then select Install.
4. Approve the administrator prompt once.

FluentWeather opens when the setup is done.


Notes
-----
The app only connects to weather.com for the weather data.
